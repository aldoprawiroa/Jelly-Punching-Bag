# Changelog

## [1.0.0](https://github.com/aldoprawiroa/Jelly-Punching-Bag/releases/tag/v1.0.0) - 2026-11-17

Rilis publik pertama Jelly Punching Bag.

### Gameplay

- Samsak jeli 3D dengan deformasi soft-body, ayunan rantai, dan material transparan.
- Jab, power punch dengan indikator charge, grab-and-swing, orbit kamera, dan zoom.
- Input mouse, keyboard, serta sentuhan.
- Empat flavour: Cherry, Blueberry, Lime, dan Cola.
- Empat wrap: Classic, Stripes, Flames, dan Plain.
- Pengaturan firmness dan wobble damping, toggle sarung tinju, serta audio sintetis opsional.
- Punch Force, rank, combo, penghitung pukulan, Best lokal, dan reset skor.

### Dokumentasi dan distribusi

- README berbahasa Indonesia dengan screenshot gameplay asli, panduan cepat, kontrol lengkap, setup lokal, dan troubleshooting.
- Publikasi statis melalui GitHub Pages dari branch `main`.
- Inisialisasi repositori dan commit pertama; `index.html` dipertahankan tanpa perubahan.

### Batasan versi ini

- Memerlukan WebGL 2 dan kemampuan GPU yang sesuai.
- Three.js serta font dimuat dari CDN; belum tersedia mode offline mandiri.
- Skor kg merupakan angka arcade, bukan pengukuran gaya fisik.
- Best hanya tersimpan pada browser/origin yang sama, tanpa sinkronisasi akun.
